# Gemini API / Veo 결제 설정

공식 문서 확인일: 2026-09-28. 메뉴명·가격·결제 방식은 계정과 시점에 따라 달라질 수 있습니다. 개인 프로젝트 ID·결제 계정 ID·키·결제 화면은 이 설명서에 포함하지 않습니다.

## 1. 사용할 프로젝트 확인

[API 키 목록](https://aistudio.google.com/app/api-keys)을 열고 AD FACTORY에 넣을 키가 속한 프로젝트를 확인합니다. [프로젝트 목록](https://aistudio.google.com/app/projects)에서 같은 프로젝트를 찾습니다. 계정에 있는 다른 프로젝트를 결제했다고 이 키의 프로젝트까지 자동 연결된 것으로 판단하지 마세요.

## 2. 결제 계정 연결

해당 프로젝트의 **결제 설정 / Set up billing**을 선택합니다. 국가·결제 정보·결제 수단을 확인하고 새 결제 계정을 만들거나 기존 계정을 연결합니다. 기존 키의 프로젝트에 결제를 연결할 수 있으므로 무조건 새 키를 만들 필요는 없습니다. [Google 공식 설정 순서](https://ai.google.dev/gemini-api/docs/billing#setup-billing)

## 3. 선불 계정 크레딧 충전

[Gemini API 결제](https://aistudio.google.com/app/billing)에서 연결한 결제 계정을 선택합니다. 선불(Prepay)이면 **크레딧 구매**를 선택하고 화면에서 요구하는 금액을 충전합니다. 공식 안내의 최소 충전은 US$5 또는 현지 통화 상당액이며 실제 화면을 따르세요. 후불 계정은 표시된 결제 절차를 따릅니다. [결제 방식](https://ai.google.dev/gemini-api/docs/billing)

GCP 프로모션 크레딧과 Gemini 선불 잔액은 구분하세요. 선불 계정에서는 Gemini용 잔액이 있어야 하며, 프로모션 크레딧 적용 여부도 별도 조건을 따릅니다. 자동 충전은 선택 사항입니다. 사용한다면 조건과 한도를 직접 확인합니다. [크레딧 안내](https://ai.google.dev/gemini-api/docs/billing#buy-credits)

## 4. 세 화면 대조

| 화면 | 확인 |
|---|---|
| API 키 | 앱에 입력할 키의 프로젝트 |
| 프로젝트 | 같은 프로젝트의 유료 등급·결제 계정·상태 |
| Billing | 그 결제 계정의 결제 방식·사용 가능한 잔액 |

## 5. 지출 한도와 사용량

[Spend](https://aistudio.google.com/app/spend)에서 같은 프로젝트를 선택하여 월 지출 한도를 확인합니다. 충전 잔액, 월 지출 한도, 분당·일별 API 호출 한도는 다른 값입니다. 비용 표시에는 지연이 있으므로 표시된 0원을 즉시 무과금의 증거로 보지 마세요. [지출 제한](https://ai.google.dev/gemini-api/docs/billing#spend-caps)

Dashboard → Usage / Rate limits에서 사용하려는 Veo 모델의 현재 한도를 확인합니다. 한도는 키마다 독립되지 않고 프로젝트에 적용되며 계정 등급 등에 따라 다릅니다. [공식 한도 안내](https://ai.google.dev/gemini-api/docs/rate-limits)

## 6. 앱 연결

AD FACTORY → 연결 설정 → Gemini API 키에 전체 키를 붙여 넣고 저장합니다. 브라우저의 설정 감지는 키 저장 여부입니다. Veo 호출 권한 확인은 아닙니다. 직접 `.env`를 수정했다면 서버 재시작이 필요합니다.

새 작업에서 사용할 Veo 모델을 선택합니다. 공개본은 고른 모델을 그대로 사용합니다. 기존 작업은 설정을 고정하므로 설정 화면 변경이 기존 작업 모델까지 변경하는 것으로 기대하지 마세요.

## 7. 호출 전에 가격 확인

Veo는 모델·해상도·영상 길이에 따라 비용이 달라집니다. **예상 비용 = 해당 옵션의 초당 단가 × 생성 초 수 × 생성 개수**로 계산하고 실제 청구액은 공급자 내역으로 확인하세요. 현재 앱의 원본 클립 길이는 8초입니다. 고정된 원화 가격을 안내하지 않으며 [공식 가격표](https://ai.google.dev/gemini-api/docs/pricing#veo-3.1)를 기준으로 합니다.

## 8. 결제했는데 실패한다면

결제 화면만으로 모든 API 호출의 정상 동작을 보장할 수는 없습니다. 앱 오류의 HTTP 코드와 상세 메시지를 확인하세요.

- `400`: 요청 매개변수·모델 지원 옵션을 확인합니다. `durationSeconds needs to be a number`는 잔액이 아니라 데이터 형식 오류입니다. `inlineData isn't supported`만으로 프로젝트 결제가 잘못됐다고 결론내리지 마세요.
- `401/403`: 키, 권한, 모델 접근 조건을 확인합니다.
- `402` 또는 결제 관련 상세 오류: 연결된 계정의 잔액·결제 상태를 확인합니다.
- `429`: 호출·사용량 한도와 상세 사유를 확인합니다.
- 공급자 응답 형식 불일치: 앱 파서 문제일 수 있습니다. 반복 결제하지 말고 비밀값을 제거한 오류로 이슈를 남깁니다.

키를 공유하지 말고, 결제 확인용 스크린샷에는 결제수단·이름·계정 ID를 가려 주세요.
