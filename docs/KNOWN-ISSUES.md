# 개발용 베타의 알려진 제한

자유로운 수정·확장을 위한 최초 공개 소스입니다. 안정화 완료 제품으로 소개하지 않습니다.

- Typecast: 문장별 TTS 합성과 영상 합성은 구현돼 있으나 실제 호출·청감·말 빠르기는 충분히 검증하지 못했습니다.
- Veo: 시작 이미지를 보내는 image-to-video 요청(8초 세로)을 구현했습니다. 실제 요청 형식과 해상도·인물 생성 옵션은 공급자 문서 기준이며 실계정 검증은 제한적입니다. Flow 모드의 화면 조작 절차([FLOW-MODE.md](../FLOW-MODE.md))도 실제 화면에서 검증하지 못했습니다.
- 모델 선택: 공개본은 선택한 Veo 모델을 그대로 요청합니다. 기존 로컬 프로토타입의 Lite → Standard 자동 치환을 제거했습니다. 계정별 사용 가능 여부는 공급자에서 확인합니다.
- 인용 근거: 광고안의 제품 인용문이 제품 자료 본문에 실제로 있는지 코드로 대조하지 않습니다(의도적으로 제거). AI 기획 검토만 근거를 확인하므로 화면의 "제품 근거" 인용문은 원문 자료와 직접 대조하세요.
- 검토 보류: 일부 기존 코드가 검토 실패를 pass와 혼용합니다. 완료·통과 표시만 믿지 말고 검토 JSON과 실제 이미지를 확인하세요. 보류·수동 승인 상태를 별도로 구현해야 합니다.
- 워크플로: 이미지·영상 표시 영역은 나뉘었지만 같은 production 상태를 공유합니다. 독립 실행·독립 재시도는 미구현입니다.
- 최종 영상: ffmpeg 8.x full 빌드가 필요하며, 완성본의 청감·자막 가독성·BGM 덕킹은 실제 렌더로 충분히 검증하지 못했습니다. 기본 설정은 사용자가 대본을 승인해야 유료 제작이 시작됩니다.
- 카피 품질: 한국어 말투 규칙을 카피 교정·대본 검토에 쓰지만 실제 모델 출력 품질은 미검증입니다. 한글로 적은 숫자는 코드 숫자 검사에 잡히지 않습니다.
- 기존 테스트 실패 2건: AI 수정 2회 한도, 거부된 소재의 수정 1회 후 중단.
- Meta: 기존 집행 코드가 남아 있지만 새 자동 작업의 기본 범위는 소재 제작입니다. 실계정 집행은 이번 공개 검증 범위에 없습니다.
- 자료 추출: 로그인·403 차단·이미지 전용 페이지를 모두 읽지는 못합니다. 자료는 작업 생성 시 고정되므로 추가 자료는 새 작업으로 반영하세요.
- 로컬 앱: 로그인·사용자 격리·키 암호화·자동 업데이트·EXE 설치본이 없습니다. `.env`는 평문입니다.
- 일부 기존 테스트는 프로토타입 동작 변경과 맞지 않습니다. [검증 기록](VALIDATION.md)에 실제 결과를 남깁니다.
