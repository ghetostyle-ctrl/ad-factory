# 상황에 맞는 광고 자막

대본 문장과 설득 순서는 바꾸지 않는다. 영상 기획에서 자막 연출을 정하고 합성기가 서체·위치·강조·아이콘을 재현한다. 시안 검토 단계는 생략한다는 사용자 결정에 따라 앱의 기획·저장·타임라인·최종 조립에 연결했다.

## 서체의 역할

| 연출 | 번들 글꼴 | 사용 맥락 |
|---|---|---|
| plain | Pretendard Bold | 성분·수치·일반 설명 |
| handwritten | Nanum Pen Script | 실제 후기·공감·혼잣말 |
| impact | Black Han Sans | 반전·단호한 핵심·행동 유도 |
| warm | Jua | 친근하고 편안한 이야기 |
| elegant | Gowun Batang Bold | 차분한 만족·고급스러운 정서 |

매 문장에 임의의 서체를 배정하지 않는다. 영상의 목소리에 맞는 기본 서체와 필요한 포인트 서체를 일관되게 쓴다. 손글씨는 읽을 수 있는 크기와 외곽선으로 보정한다. 모든 글꼴은 원본 파일·라이선스·출처를 함께 배포하며 OS 설치 글꼴이나 원격 폰트 로딩에 의존하지 않는다.

## 배치와 강조

- 실사는 얼굴 아래 가슴 부근, 설명 장면은 03 라벨 아래의 기존 자막 안전 영역을 사용한다. 자동 얼굴/제품 추적을 뜻하지 않는다.
- 일반 글자는 밝은 흰색, 외곽선과 짧은 그림자로 읽히게 한다. 긴 불투명 바는 쓰지 않는다.
- 핵심어는 대본에서 그대로 가져온 연속 문자열 하나다. 문장 전체를 언제나 강조하지 않는다. 상황에 맞는 따뜻한 노랑·코랄·민트 계열 중 정한 색을 반복 사용한다.
- 핵심어에만 색과 8% 크기 차이를 주고, 구절 전체는 서체 역할에 따라 짧은 팝 또는 페이드로 등장한다. 완성 문구가 한 번에 읽히게 한다. 글자 와이프·카피 생략·독해를 방해하는 반복 흔들기는 쓰지 않는다.
- 아이콘은 말에 직접 등장하는 물건/개념만 지원 목록에서 고른다. 잎·기름방울·캡슐·병·가게·시계·금액을 나타내는 로컬 벡터를 사용한다. 효과/인증/수익을 새로 주장하는 장식은 쓰지 않는다.
- 설명 장면은 plain 자막으로 읽기 우선, 별도 아이콘과 강한 동작을 억제한다. 기존 03 라벨 폰트/스타일은 유지한다.
- 실제 글꼴의 진행폭으로 줄을 나누고 원문 전체를 보존한다. 누락 글자는 읽기 좋은 기본 글꼴로 처리하고, 안전 영역에 들어오지 않는 자막은 오류로 알려야 한다.

## 연결 범위와 검증

새 장면 기획에 captionDirection(tone, keyword, icon)을 저장한다. 별도 유료 모델 호출을 추가하지 않는다. 이전 대본은 기존 의미 태그에 따라 기본 설명·후기 손글씨·마지막 행동 강조의 세 계열을 선택하며 저장 대본이나 승인 해시는 다시 쓰지 않는다. 저장된 완성 MP4는 자동 재렌더하지 않는다.

실사 원본의 10초 로컬 조립에서 다섯 서체와 단어 강조·캡슐 아이콘을 360×640으로 확인했다. 설명 컷은 기존 03 라벨과 하단 자막이 겹치지 않는 프레임을 확인했다. 긴 문구 거부·미지원 글자 기본 폰트 전환·원문 불변·무관한 아이콘 제거는 자동 검사로 확인한다. 새 유료 생성 영상의 최종 미감과 자동 기획의 서체 선택 품질은 미검증이다.

## 구현 파일

- 역할/크기/색: shared/caption-direction.ts. 1080×1920 기준 일반64px, 손글씨104px, 강한 강조82px, 둥근체76px, 바탕체72px. 글꼴마다 실제 글자 높이가 달라 같은 숫자를 강제하지 않는다.
- 실사 중심 y1228, 설명 중심 y1464. 얼굴/제품의 자동 위치 추적은 없으며 최종 가림 확인이 필요하다.
- 기획 지침: instructions/script.md의 AD_CAPTION_DIRECTION_RULES.
- 글꼴 원본·OFL 라이선스·출처·측정값: assets/fonts/captions/.
- 합성: server/render/caption-ass.ts, caption-fonts.ts, caption-icons.ts. 글꼴 원본 해시와 글리프 지원 여부를 검사한다.
